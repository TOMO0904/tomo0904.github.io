Deep Space Care — LINE mental-care bot

A Gemini chatbot that screens for crisis messages before the model sees them and hands those over to a human.

Problem
Crews in isolated, high-latency environments cannot rely on ground support for first-line emotional support, and a chatbot must never improvise when someone is in crisis.
Solution
A LINE bot that replies with empathy, a small self-care step and a question via Gemini, checks for crisis expressions before any text reaches the model, hands over to human support, and falls back to fixed replies on timeout. Webhooks are verified with HMAC-SHA256.
  • Python
  • FastAPI
  • LINE Messaging API
  • Gemini API
  • SQLite
  • pytest
  • Docker
